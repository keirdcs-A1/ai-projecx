Local Model Benchmark.

A local evaluation tool for Ollama models, measuring tool calling, executable coding tasks and general capability alongside real disk usage.

Open sourceOllamaEvaluationsLocal-first
View on GitHub
THE QUESTION

Which of the models on your own machine can reliably do the work you actually need?

  • Tool calling scored on arguments and order
  • Coding answers checked by real tests
  • Blind grading and shared-layer disk inventory

The approach

Run repeatable suites with controlled settings, separate disqualifying failures from scores and grade subjective answers blind. The disk inventory accounts for shared model layers instead of simply adding advertised sizes.

Running it locally

Runs on your own computer with Node 20+ and Ollama. The hosted website cannot access your local models or execute its coding battery. The public MIT-licensed repository includes setup instructions. Model-generated coding answers are executed locally with guardrails, not a security sandbox.

GET STARTED / NODE 20+ & OLLAMA REQUIRED

Run your own benchmark.

git clone https://github.com/keirdcs-A1/localmodelbench.git
cd localmodelbench
node server.js

Then open http://127.0.0.1:4321 on your computer. Ollama must be running locally. Read the repository’s setup and coding-execution notes before starting.
